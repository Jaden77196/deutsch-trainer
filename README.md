# Deutsch · 德语训练

一个零依赖的德语学习应用，为「刚学会字母发音、目标是能和母语者交流」的初学者设计。手机浏览器打开即可使用，可「添加到主屏幕」当 App 用。

## 在线使用

**https://jaden77196.github.io/deutsch-trainer/**

## 内容规模

| 模块 | 规模 |
|---|---|
| A1 词汇 | 30 组 |
| A2 词汇 | 19 组 |
| B1 词汇 + 日常口语高频句 | 22 组 |
| B2 词汇 | 15 组 |
| **合计** | **863 词/句 · 86 组** |
| **语法精讲 + 练习** | **33 个知识点 / 272 题** |
| 阅读理解 | 10 篇（A1→B1 递进） |

**语法精讲 + 练习**是讲义和习题合体的：每个知识点一条，先讲规则（一句话核心 + 小表格 + 例句 + 提醒），底部直接「练这 N 题」。**答错时会自动把这条的核心规则弹出来，再给这道题的具体讲解**，不用翻回去找讲义。

知识点按细粒度拆分，例如「介词配格」拆成第三格口诀 / 第四格口诀 / 双向介词三条，「语序」拆成陈述句 / 疑问句两条。

**日常口语高频句**是单独一块（8 组，如「表达不确定」「请求与帮忙」「同意与反对」「追问与澄清」）——真人对话里你要说的是整句，不是单词，这一块专门练这个。

## 功能

**四种词汇练习模式**（每组都有）

- **学习生词**：看德语词 + 听发音，再显示中文、读音提示、例句
- **选词填空**：看例句，选出正确的词
- **复习生词**：中德互译，方向随机
- **默写生词**：听发音／看中文写出德语（名词含冠词），可一键输入 ä ö ü ß

**语法精讲 + 练习**

33 个知识点，按 A1/A2/B1 分组。每条包含讲义部分（核心规则、可选小表格、例句、提醒）和专属习题。讲完直接练，答错自动回显规则。

**阅读理解**

10 篇文章，随词汇进度解锁。每篇配 3–4 道理解题，可展开中文翻译。

## 掌握度机制

默写**一轮全部答对才算一遍**，累计 **5 遍满分**解锁下一组。进度显示为五个圆点（呼应德语 Umlaut 的两点标记）。

名词按 der / die / das 三色区分，从第一课就建立词性意识。

## 设置项

- **名词必须带冠词**：默写时 der/die/das 写错则整题算错
- **严格模式**：默写出错时掌握度清零重来（关闭则只有全对的轮次计入，答错不清零）
- **语速**：正常 / 慢速 / 很慢
- **解锁全部内容**：跳过「五遍满分」的顺序限制，可自由跳到任意一组

## 本地使用

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

窗口会显示手机访问地址（需同一 WiFi）。也可双击 `start-server.cmd`。

## 文件说明

**`index.html` 是自动生成的，不要直接改它**——改了会被下次构建覆盖。

| 文件 | 内容 |
|---|---|
| `template.html` | 应用本体（界面 + 逻辑）← **要改界面/逻辑改这里** |
| `content-a1.js` / `content-a2.js` / `content-b1.js` / `content-b2.js` | 分级词汇 |
| `content-phrases.js` | 日常口语高频句 |
| `content-topics-a.js` / `content-topics-b.js` | **语法精讲 + 练习**（讲义与习题合体） |
| `content-readings.js` | 阅读文章 |
| `index.html` | **构建产物**：以上全部内联成单文件 |
| `build.ps1` | 构建脚本 |
| `serve.ps1` / `start-server.cmd` | 本地服务器 |

### 为什么是单文件

App 主要在手机上、在不稳定的网络下使用。单文件 = **1 个请求**；拆成 8 个内容文件 = **9 个请求**，只要有一个失败或超时，页面就是空壳。内联之后还顺带能离线用、能直接从文件打开。

### 改完怎么上线

```bash
powershell -ExecutionPolicy Bypass -File build.ps1   # 重新生成单文件 index.html
git add -A && git commit -m "..." && git push
```

GitHub Pages 会在约 1 分钟后自动更新。**改完内容一定要先跑 build.ps1**，否则线上还是旧的。

### 加词格式

```js
['die Familie', '家庭', '读音提示', 'Meine {Familie} ist groß.', '我的家庭很大。', 'n']
```

- 名词带上冠词（程序据此给 der/die/das 上色并校验）
- 例句用 `{ }` 标出可挖空部分（填**变位后**的形式，如 `{bin}`）——**这一项是必填的**，缺了会导致选词填空无法生成
- 词性：`n` 名词 / `v` 动词 / `a` 形容词 / `x` 其他 / `p` 整句
- 组的 `lv` 字段决定它归在哪个等级下
