# Deutsch · 德语训练

一个零依赖的德语学习应用，为「刚学会字母发音、目标是能和母语者交流」的初学者设计。手机浏览器打开即可使用，可「添加到主屏幕」当 App 用。

## 在线使用

**https://jaden77196.github.io/deutsch-trainer/**

## 内容规模

| 模块 | 规模 |
|---|---|
| A1 词汇 | 30 组 |
| A2 词汇 | 19 组 |
| B1 词汇 + 日常口语高频句 | 22 组 |
| B2 词汇 | 15 组 |
| **合计** | **863 词/句 · 86 组** |
| **语法讲义（速记捷径）** | **24 条** |
| 语法专项训练 | 23 个专题 / 184 题 |
| 阅读理解 | 10 篇（A1→B1 递进） |

**语法讲义**是速记卡，不是教科书——一条一个捷径，30 秒读完。例如「名词性别不用背，看词尾就能判」「四个格里只有阳性单数会变（der→den）」。卡里带小表格、例句和一条提醒，可以像翻单词卡一样逐条翻。

**日常口语高频句**是单独一块（8 组，如「表达不确定」「请求与帮忙」「同意与反对」「追问与澄清」）——真人对话里你要说的是整句，不是单词，这一块专门练这个。

## 功能

**四种词汇练习模式**（每组都有）

- **学习生词**：看德语词 + 听发音，再显示中文、读音提示、例句
- **选词填空**：看例句，选出正确的词
- **复习生词**：中德互译，方向随机
- **默写生词**：听发音／看中文写出德语（名词含冠词），可一键输入 ä ö ü ß

**语法讲义**

24 条速记捷径，按 A1/A2/B1 分组，卡片式阅读。每条包含：一句核心规则、可选的小表格、例句、一条提醒（通常是例外或最容易翻车的地方）。

**语法专项训练**

23 个专题，从 sein/haben 变位、四个格、语序，到完成时、形容词词尾、关系从句、虚拟式 II、被动语态。**每题答完都有讲解**——语法题的价值就在那句解释。

**阅读理解**

10 篇文章，随词汇进度解锁。每篇配 3–4 道理解题，可展开中文翻译。

## 掌握度机制

默写**一轮全部答对才算一遍**，累计 **5 遍满分**解锁下一组。进度显示为五个圆点（呼应德语 Umlaut 的两点标记）。

名词按 der / die / das 三色区分，从第一课就建立词性意识。

## 设置项

- **名词必须带冠词**：默写时 der/die/das 写错则整题算错
- **严格模式**：默写出错时掌握度清零重来（关闭则只有全对的轮次计入，答错不清零）
- **语速**：正常 / 慢速 / 很慢
- **解锁全部内容**：跳过「五遍满分」的顺序限制，可自由跳到任意一组

### 加词格式

```js
['die Familie', '家庭', '读音提示', 'Meine {Familie} ist groß.', '我的家庭很大。', 'n']
```

- 名词带上冠词（程序据此给 der/die/das 上色并校验）
- 例句用 `{ }` 标出可挖空部分（填**变位后**的形式，如 `{bin}`）——**这一项是必填的**，缺了会导致选词填空无法生成
- 词性：`n` 名词 / `v` 动词 / `a` 形容词 / `x` 其他 / `p` 整句
- 组的 `lv` 字段决定它归在哪个等级下
