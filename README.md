# Deutsch · 德语训练

一个零依赖的单文件德语学习 App。为「刚学会字母发音、目标是能跟母语者交流」的初学者设计。

## 功能

- **学习生词**：先看德语词 + 发音，再显示中文、读音提示、例句
- **选词填空**：看例句，选出正确的词
- **复习生词**：中德互译，混合抽测
- **默写生词**：听发音／看中文，写出德语（含冠词），可一键输入 ä ö ü ß
- **掌握度门槛**：默写**一轮全对才计一遍**，累计 **5 遍满分**解锁下一组；严格模式下出错清零
- **阅读理解**：6 篇难度递进的文章，随词汇进度解锁

进度存在手机浏览器本地（localStorage），换设备不互通。

## 在手机上使用

**方式一：同一 WiFi 下访问（推荐）**

1. 电脑和手机连同一个 WiFi
2. 双击 `start-server.cmd`（或运行 `powershell -File serve.ps1`）
3. 窗口会显示手机访问地址，形如 `http://192.168.x.x:8787/`，手机浏览器打开即可

**方式二：直接拷文件**

把 `index.html` 传到手机，用浏览器打开。单文件、零依赖、离线可用。

**添加到主屏幕**（更像原生 App）

- iPhone Safari：打开后点「分享」→「添加到主屏幕」
- Android Chrome：菜单 →「安装应用」或「添加到主屏幕」

## 内容

16 组 A1 核心词汇（160 词），覆盖问候、数字、家庭、饮食、餐厅、交通、购物、住宿、天气等旅行日常主题，每组 10–13 词。词汇组和阅读文章都在 `index.html` 顶部的 `GROUPS` / `READINGS` 里，想加词直接往里加一行即可。
